### Запуск программ

#### Python
```bash
cd python

# Интерактивный ввод
python hello.py

# Через аргумент командной строки
python hello.py Иван
python hello.py "Имя Фамилия"
```

#### Go
```bash
cd go

# Интерактивный ввод
go run main.go

# Через аргумент командной строки
go run main.go Иван
go run main.go "Имя Фамилия"
```

**Ожидаемый вывод (пример):**
```
Hello, Иван! Current time: 2026-09-11 12:34:56
[Python] Execution time: 0.XXXX ms
```
